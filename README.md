# MetaForge - Autonomous Local AI App Builder

**MetaForge** は、ブラウザだけで動作する自律型 AI Webアプリ構築ツールです。
Node.js や Python などのバックエンド環境は一切不要。`index.html` を開くだけで、最新の **Gemini** モデルがあなたの代わりにコーディング、デバッグ、プレビュー作成、そしてプロジェクト管理を行います。

本ツールは、LLMの自律的な思考と実行のループを定義する **ALLA (Autonomous LLM Loop Architecture)** に基づいて設計されており、単なるチャットボットではなく、自律的に試行錯誤を行うエンジニアエージェントとして振る舞います。

## 🚀 主な特徴

*   **完全ローカル & サーバーレス**: すべての処理はブラウザ内の JavaScript で完結します。データが外部サーバー（Google API以外）に送信されることはありません。
*   **自律型エージェント**: AIが「思考 (Thinking) → 計画 (Plan) → 実行 (Tools) → 確認 (Preview/Screenshot)」のループを自律的に回し、動くアプリを完成させます。
*   **仮想ファイルシステム (VFS)**: メモリ上にプロジェクト構造を構築し、リアルタイムでプレビューを実行します。
*   **プロジェクト永続化**: IndexedDB を使用し、作業内容は自動的にブラウザ内に保存されます。
*   **LPML (LLM-Prompting Markup Language)**: AIとの通信に最適化された独自のマークアップ言語を採用し、複雑なファイル操作を正確に指示します。

## 🧠 理論的背景: ALLA アーキテクチャ

MetaForge は、**ALLA (Autonomous LLM Loop Architecture)** という設計思想に基づいています。これは、エージェントの振る舞いを「世界状態の再帰的な変換プロセス」としてモデル化したものです。

### 1. 世界状態 ($\Omega$)
システムは「現在の世界」として以下の情報を保持します。
*   **仮想ファイルシステム ($\mathcal{F}$)**: 作成中のソースコードや画像データ。
*   **対話履歴 ($H$)**: ユーザーとの会話だけでなく、AIの思考ログ、ツールの実行結果、スクリーンショットを含みます。これらは単なるログではなく、可変な「記憶」として扱われ、必要に応じて圧縮・整理されます。

### 2. 自律ループ (The Loop)
ユーザーが指示を出すと、AIは以下のサイクルを自動的に回し続けます。

1.  **射影 (Projection)**: 現在の世界状態を、LLMが理解可能なコンテキストに変換します。
2.  **生成 (Generation)**: LLMが次のアクション（コードの記述、プレビューの確認など）を決定します。
3.  **実行 (Execution)**: 決定されたツール（`create_file`, `preview` 等）を実行し、世界を更新します。
4.  **観察 (Observation)**: 実行結果（エラーログやスクリーンショット）を認識し、次の行動を決定します。

### 3. 制御シグナル ($\sigma$)
このループは、AI自身が「完了した」と判断するか、ユーザーの助けが必要になるまで止まりません。
*   `CONTINUE`: 作業継続（例：コードを書いたので、次はプレビューして確認する）。
*   `HALT`: 一時停止（例：仕様が不明確なのでユーザーに質問する `<ask>`）。
*   `TERMINATE`: タスク完了（例：すべての機能が実装できた `<finish>`）。

## 📖 使い方

### 1. 前提条件
*   **Google Gemini API Key**: [Google AI Studio](https://aistudio.google.com/) で取得してください。
*   **推奨モデル**: `gemini-2.0-flash` または `gemini-1.5-pro`。
*   **ブラウザ**: Google Chrome, Edge, Safari などのモダンブラウザ（最新版推奨）。

### 2. 起動方法
1.  このリポジトリをダウンロード（Clone）します。
2.  フォルダ内の `index.html` をブラウザで直接開きます。
3.  画面右上の入力欄に **API Key** を入力し、`Save` ボタンを押します。

### 3. アプリ開発の流れ
チャット欄に作りたいアプリのアイデアを入力してください。

> **プロンプト例:**
> *   「ブロック崩しゲームを作って。スコア機能と効果音もつけて」
> *   「CSVファイルを読み込んでグラフ表示するダッシュボードを作って」
> *   「モダンなデザインのTODOリストアプリ。データはローカルストレージに保存して」

AIは以下の手順で開発を進めます：
1.  **要件定義**: どのようなファイルが必要か考えます。
2.  **コーディング**: HTML, CSS, JavaScript ファイルを作成します。
3.  **プレビュー & 視覚確認**: 内部ブラウザでコードを実行し、スクリーンショットを撮影して「見た目」を確認します。
4.  **修正**: エラーやデザインの崩れがあれば、自律的に修正を行います。
5.  **完了報告**: 完成したと判断したら、あなたに報告します。

### 4. 便利な機能
*   **ファイル編集**: 左サイドバーのファイルをクリックすると、エディタが開きます。手動で修正を加えることも可能です。
*   **画像アップロード**: チャット欄のクリップボードアイコンから画像をアップロードし、「このデザインにして」と指示できます。
*   **ZIPダウンロード**: サイドバーのダウンロードボタンから、作成したプロジェクトをZIP形式で保存できます。

## ⚠️ 技術的制約 (Limitations)

本ツールはブラウザのサンドボックス内で動作するため、以下の制約があります。

### 1. モジュールシステムの制限 (No ESM)
生成されるアプリは `file://` プロトコルや Blob URL 上で動作するため、ES Modules (`import` / `export`) が使用できません。
*   ❌ `import React from 'react';`
*   ✅ `<script src="https://cdn.../react.js"></script>` (CDN利用)
*   ✅ グローバル変数を使用した実装 (例: `window.App = ...`)

AIはこの制約を理解するように調整されていますが、時折 `import` を書いてしまうことがあります。その場合は「importを使わずにCDNで書いて」と指示してください。

### 2. 外部通信の制限 (CORS)
作成されたアプリから外部API（天気予報APIなど）を叩く場合、CORS（Cross-Origin Resource Sharing）の制限を受けることがあります。

### 3. データ永続化の範囲
プロジェクトデータはブラウザの **IndexedDB** に保存されます。
*   ブラウザのキャッシュをクリアするとデータが消える可能性があります。
*   重要なデータはこまめに「ZIPダウンロード」でバックアップしてください。

## 📂 ディレクトリ構成

```text
metaforge/
├── index.html          # アプリケーションの入り口
├── src/
│   ├── lib/            # 【ALLA Core】 (汎用エンジン)
│   │   ├── engine.js   # 自律ループの制御ロジック
│   │   └── state.js    # 世界状態の管理
│   │
│   └── app/            # 【Implementation】 (固有の実装)
│       ├── main.js     # アプリ起動スクリプト
│       ├── config.js   # システムプロンプト設定
│       ├── adapters/   # Gemini API や Storage との接続
│       ├── world/      # 仮想ファイルシステムとコンパイラ
│       ├── tools/      # AIが使用するツール群 (Create, Edit, Preview...)
│       └── ui/         # UIコントローラー
└── README.md
```
