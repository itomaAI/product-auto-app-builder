# MetaForge - Autonomous Local AI App Builder

**MetaForge** は、ブラウザだけで動作する次世代の自律型 AI アプリ開発環境（IDE）です。
Node.js や Python などのバックエンド環境は一切不要。`index.html` を開くだけで、最新の **Gemini 3** モデルがあなたの代わりにコーディング、デバッグ、プレビュー作成、そしてプロジェクト管理を行います。

本ツールは、人間とAIが環境を共有しながら開発を進めるための新理論 **REAL (Recursive Environment-Agent Loop)** アーキテクチャに基づいて設計されており、単なるチャットボットではなく、自律的に試行錯誤を行うエンジニアエージェントとして振る舞います。

[**今すぐ試す**](https://itomaai.github.io/product-auto-app-builder/)

## 🚀 主な特徴

*   **完全ローカル & サーバーレス**: すべての処理はブラウザ内の JavaScript で完結します。データが外部サーバー（Google API以外）に送信されることはありません。
*   **VSCodeライクな操作性**: ディレクトリ階層に対応したファイルエクスプローラー、タブ補完、ドラッグ＆ドロップでのファイル移動/アップロード、画像プレビューなどを備えています。
*   **自律型エージェント**: AIが「思考 (Thinking) → 計画 (Plan) → 実行 (Tools) → 確認 (Preview/Screenshot)」のループを自律的に回し、動くアプリを完成させます。
*   **双方向の同期 (Event Injection)**: あなたが手動でコードを修正したりファイルを移動したりすると、その操作は即座にAIの「記憶」に同期されます。AIは環境の変化を認識した上で、次の開発ステップを提案します。
*   **LPML (LLM-Prompting Markup Language)**: AIとの通信に最適化された独自のマークアップ言語を採用し、複雑なファイル操作を正確に指示します。

## 🧠 理論的背景: REAL アーキテクチャ

MetaForge は、**REAL (Recursive Environment-Agent Loop)** という設計思想に基づいています。これは、エージェントシステムを以下の3層構造として定義し、人間の「予測不能な操作」とAIの「論理的な思考」を矛盾なく統合するモデルです。

### 1. 認知層 (L1: Cognitive Layer)
*   AI（LLM）が純粋な思考を行う層です。現在の状況からコンテキストを読み解き、「次になにをすべきか」を計画します。

### 2. 制御層 (L2: Control Layer)
*   AIの自律ループを管理する層です。自律的に作業を続けるか (`CONTINUE`)、ユーザーに質問するために止まるか (`HALT`) を判断します。ここで人間は「質問に答えるアドバイザー」として機能します。

### 3. 状態層 (L3: State Layer)
*   ファイルシステムや履歴の実体を管理する層です。
*   ここにおいて人間は、AIのロジックとは無関係にファイルを書き換えたり削除したりする「管理者 (Supervisor)」としての特権を持ちます。
*   REALアーキテクチャは、人間のこの操作を検知し、**Event Injection** という仕組みでAIの記憶に強制的に書き込むことで、開発コンテキストの整合性を保ちます。

## 📖 使い方

### 1. 前提条件
*   **Google Gemini API Key**: [Google AI Studio](https://aistudio.google.com/) で取得してください。
*   **必須モデル**: `gemini-3-pro` または `gemini-3-flash`（推奨）。
*   **ブラウザ**: Google Chrome, Edge, Safari などのモダンブラウザ（最新版推奨）。

### 2. 起動方法
1.  このリポジトリをダウンロード（Clone）します。
2.  フォルダ内の `index.html` をブラウザで直接開きます。
3.  画面右上の入力欄に **API Key** を入力し、`Save` ボタンを押します。

### 3. アプリ開発の流れ
チャット欄に作りたいアプリのアイデアを入力してください。

> **プロンプト例:**
> *   「ブロック崩しゲームを作って。スコア機能と効果音もつけて」
> *   「CSVファイルを読み込んでグラフ表示するダッシュボードを作って」
> *   「モダンなデザインのTODOリストアプリ。データはローカルストレージに保存して」

AIは以下の手順で開発を進めます：
1.  **要件定義**: どのようなファイルが必要か考えます。
2.  **コーディング**: HTML, CSS, JavaScript ファイルを作成します。
3.  **プレビュー & 視覚確認**: 内部ブラウザでコードを実行し、スクリーンショットを撮影して「見た目」を確認します。
4.  **修正**: エラーやデザインの崩れがあれば、自律的に修正を行います。

### 4. 人間による介入（Human-in-the-loop）
開発中、あなたはいつでも介入できます。
*   **ファイル編集**: 左サイドバーのファイルをクリックしてエディタを開き、直接コードを修正できます。
*   **ファイル操作**: 右クリックメニューから、新規ファイル作成、リネーム、複製、削除、アップロードが可能です。
*   **チャットでの指示**: 「ここの色をもっと明るくして」「バグってるから直して」と追加指示を出せます。

## ⚠️ 技術的制約 (Limitations)

本ツールはブラウザのサンドボックス内で動作するため、以下の制約があります。

### 1. モジュールシステムの制限 (No ESM)
生成されるアプリは `file://` プロトコルや Blob URL 上で動作するため、ES Modules (`import` / `export`) が使用できません。
*   ❌ `import React from 'react';`
*   ✅ `<script src="https://cdn.../react.js"></script>` (CDN利用)
*   ✅ グローバル変数を使用した実装 (例: `window.App = ...`)

AIはこの制約を理解するように調整されていますが、時折 `import` を書いてしまうことがあります。その場合は「importを使わずにCDNで書いて」と指示してください。

### 2. 外部通信の制限 (CORS)
作成されたアプリから外部API（天気予報APIなど）を叩く場合、CORS（Cross-Origin Resource Sharing）の制限を受けることがあります。

### 3. データ永続化の範囲
プロジェクトデータはブラウザの **IndexedDB** に保存されます。
*   ブラウザのキャッシュをクリアするとデータが消える可能性があります。
*   重要なデータはこまめに「ZIPダウンロード」でバックアップしてください。

│   │   └── state.js    # 世界状態の管理
│   │
│   └── app/            # 【Implementation】 (固有の実装)

│       ├── config.js   # システムプロンプト設定
│       ├── adapters/   # Gemini API や Storage との接続
│       ├── world/      # 仮想ファイルシステム (VFS) とコンパイラ
│       ├── tools/      # AIが使用するツール群
│       └── ui/         # UIコンポーネント (Chat, Editor, Explorer...)
